# CYBER TETRIS - Neon Arcade & Online Battle

エレガントなサイバーネオン調のビジュアルとエキサイティングなアニメーション、本格的なテトリス競技仕様（SRS、7-Bag、HOLD、ロックディレイ、コンボシステム、Web Audio API 効果音）、そして**リアルタイム通信対戦（おじゃまライン送り合い & 相殺バトル）**を備えたモダンなWebテトリスゲームです。

---

## 🎮 特徴 (Features)

### ⚔️ リアルタイム通信対戦 (Online Battle)
- **Codespaces & グローバル対戦対応**:
  - Node.js + WebSocket による超低遅延ルームシステム（`server.js`）。
  - Codespaces のポート 8000 を「Public」に設定することで、世界中のプレイヤーとURLひとつで即座に対戦可能！
- **ルーム作成 & 招待URL共有**:
  - ワンクリックで 4 文字のルームコード（例: `ABCD`）を発行。
  - 「COPY LINK」ボタンで招待用URL（`?room=ABCD`）をコピーし、相手に送るだけで即時マッチング。
- **おじゃまライン攻撃 & 相殺（Offset）システム**:
  - 2ライン消去: 1ライン攻撃
  - 3ライン消去: 2ライン攻撃
  - 4ライン（TETRIS）: 4ライン攻撃
  - コンボボーナス: 連続消去ごとに攻撃ライン数アップ！
  - **相殺システム**: 相手から送られてきた保留おじゃまラインは、自分がライン消去することで相殺（キャンセル）可能。相殺しきれなかったおじゃまラインはミノ接地時に下からせり上がります。
- **公平な競技性 (Fair Seeded 7-Bag)**:
  - 対戦開始時にサーバーから共有乱数シードを配信し、両プレイヤーに全く同一順序のミノが配牌されます。
- **リアルタイム相手盤面プレビュー & おじゃまメーター**:
  - 相手の盤面、落下中ミノ、スコア、ライン数をリアルタイムホログラム表示。
  - 自分の盤面横に保留中のおじゃまライン警告ゲージを配置。

### 💎 Cyber Neon / Dark Arcade Visuals
- **ガラスモーフィズム & 発光UI**: すりガラス風パネル（`backdrop-filter`）、ネオングロー、微細な発光ボーダー、Orbitron フォント。
- **立体ジュエルトーンブロック**: 光沢・ハイライト・ベベル処理が施された宝石のようなブロック。
- **パルス発光ゴーストピース**: 上品に明滅するネオンワイヤーフレームの着地予測。

### 🎆 エキサイティングなエフェクト
- **パーティクル爆発**: ライン消去時の火花スパーク、ハードドロップ時の衝撃波ダスト。
- **スクリーンシェイク**: ハードドロップやテトリス、おじゃまライン突入時の画面微振動。
- **ポップアップテキスト**: 「SINGLE」「DOUBLE」「TRIPLE」「TETRIS!」「COMBO xN」「OFFSET!」などの浮遊演出。

### 🔊 Web Audio API プロシージャル効果音
- 外部音声アセット不要・超軽量でゼロレイテンシーの効果音（移動、回転、ハードドロップ、消去アルペジオ、テトリスファンファーレ、ゲームオーバー、カウントダウン、おじゃま警報・せり上がり、勝利・敗北ファンファーレ）。
- `M` キーまたは画面のサウンドボタンでいつでもミュート切替可能。

## 🚀 起動方法 & 対戦の始め方

### 1. サーバーの起動
```bash
npm start
# または
node server.js
```
サーバーが `http://localhost:8000` で起動し、Web画面の配信とWebSocket通信を同時に処理します。

### 2. 通信対戦の遊び方
1. 画面上部の **「⚔️ ONLINE BATTLE」** ボタンをクリック。
2. **ホスト（親）**:
   - 「CREATE ROOM」を押すと4文字のルームコードが発行されます。
   - 「COPY LINK」を押して招待リンクを相手に共有します。
3. **ゲスト（子）**:
   - 招待リンクを開くか、ルームコードを入力して「JOIN」を押します。
4. ホストが **「START BATTLE」** を押すと、3・2・1・FIGHT! のカウントダウンと共に対戦がスタート！
5. 複数ライン消去でおじゃまブロックを送り合い、相手の盤面を埋め尽くした（ノックアウトした）プレイヤーが勝利です！

> [!TIP]
> **GitHub Codespaces でのグローバル公開**:
> VS Code / Codespaces の「PORTS (ポート)」タブを開き、ポート `8000` の「Visibility (表示設定)」を **Private** から **Public** に変更すると、生成された URL（`https://...app.github.dev`）を通じて世界中のPCやスマホから対戦に参加できるようになります！

## 🏫 授業で使うとき (Codespaces)

1. このリポジトリを自分のアカウントに **Fork** し、Fork 先で Codespace を作成します。
2. 起動すると `npm ci` が自動で行われます（サーバーは**自動では起動しません**）。下のパネルの「ターミナル」で `npm start` を実行してください。このターミナルはサーバーが動いている間、使い続けます。ほかの作業は、ターミナル右上の「＋」で新しいターミナルを開いて行います。
3. 「PORTS」タブで、ポート 8000 の「表示範囲（Visibility）」は最初 **Private** です。**必ず手動で Public に変更します**（8000 の行を右クリック → 「ポートの表示範囲」 → 「Public」。英語表示の場合は「Port Visibility」。`devcontainer.json` では Public に設定できません）。ターミナルなら `gh codespace ports visibility 8000:public` でも変更できます。
4. **Public は URL を知っていれば誰でも開ける**ので、個人情報は入力しないでください。
5. サーバーを止めてしまったら、もう一度 `npm start` を実行します。Codespace を停止して再開したときも、`npm start` を実行し直します。
6. Codespace を再開したときに表示範囲が **Private** に戻っていたら、もう一度 Public に変更します。

## 📂 プロジェクト構成

```
.
├── index.html          # メインHTML (SOLO & 2人対戦レイアウト、モーダル)
├── style.css           # Cyber Neon スタイルシート & 対戦アリーナ装飾
├── server.js           # HTTP静的配信 & WebSocketリアルタイムルームサーバー
├── package.json        # Node.js 依存設定 (ws)
├── src/
│   ├── network.js      # WebSocket クライアントマネージャー (ルーム、攻撃、同期)
│   ├── constants.js    # 定数、ジュエルトーン・おじゃま色、SRSキックデータ、配点
│   ├── piece.js        # ミノ形状、回転、SRSウォールキック、接地判定
│   ├── board.js        # 盤面グリッド、衝突判定、ライン消去、おじゃま挿入
│   ├── particle.js     # パーティクルエンジン (火花、着地ダスト、浮遊テキスト)
│   ├── audio.js        # Web Audio API プロシージャルシンセサイザー (対戦SE含む)
│   ├── renderer.js     # Canvas 描画エンジン (自盤面 & 相手盤面ホログラム描画)
│   ├── game.js         # ゲームエンジン (シード乱数、ホールド、相殺、攻撃送出)
│   └── main.js         # エントリーポイント & UI・ネットワークイベント統括
```
